# Superstore Sales Analysis | Python, MySQL, Power BI

## Problem
Company ki sales high thi but profit low tha. Pata lagana tha kyun.

## Solution
- 10k+ rows ko Pandas se clean kiya
- MySQL me 10+ business queries likhe
- Power BI me interactive dashboard banaya

## Key Insights
- West Region me sabse zyada loss shipping cost ki wajah se
- Technology category sabse profitable hai
- Top 5 products 40% profit laate hain

## Tools Used
Python, MySQL, Power BI, Excel
